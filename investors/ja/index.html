01 課題

採用も、答えも、支払いも。誰かが取り分を取っていきます。

インドでは、仕事に就くこと、確かな答えを得ること、代金を受け取ることのどれもが、各段階で手数料を取る仲介者を通ります。

  • 採用。採用担当者は履歴書を見るためにお金を払い、求職者は聞かれるたびに電話番号を渡します。
  • 答え。確かな答えがほしい人は、分単位で料金を払います。
  • 支払い。小さな販売者は、売るたびに一部を取られます。

03 これまで試されたこと

誰もが何とかやっています。それでも間にいる誰かが報酬を得ています。

  • 採用担当者はキーワードで検索し、履歴書を一通ずつ手で読みます。スキルテストは月額US$79から。HackerRankの料金、2026年
  • 求職者はあらゆる所に応募し、誰にでも電話番号を教えます。
  • 助言を求める人は分単位の料金でチャットし、確かめようのない答えを受け取ります。
  • 小さな販売者はゲートウェイに手数料を払うか、領収書も返金もウォレットもない、UPIのQRコードだけを掲げます。

04 明かす

Asanoha：一つのアカウント、一つの決済基盤、一つのウォレット。その上にアプリが載ります。

共通の部分は一度だけつくり、決済のコードは公開します。その上のどのアプリも最初からそれを使えるので、サインインにも、支払いにも、返金にも仲介者は要りません。

実数 コードやデータベースから取得 · 計画 自社の目標または推計 · 市場 第三者の数値

小さな人材紹介会社の採用担当者が、バックエンド開発者を一人探しています。

キーワード検索では、手で読む履歴書が何百通も返ってきます。スキルテストは月額US$79からです。

People Pitchersは実際の成果をもとに人を並べ、一致の根拠となったプロフィールの一文をそのまま引用します。電話番号を誰に見せるかは求職者が決め、開示はすべて記録されます。

UPIで₹10,000を受け取る販売者は、そのうち₹200をゲートウェイに渡し、さらにGSTもかかります。

もう一つの選択肢は、領収書も返金もウォレットもない、UPIのQRコードだけを掲げることです。

Noha Payは、代金を販売者自身のUPI IDに直接送り、預かることはありません。Noha Moneyは、キャッシュバックと返金のための一つのウォレットを加えます。どちらもオープンソースなので、誰でもコードを読み、動かせます。

git clone -b noha-pay https://github.com/jervis446/NohaPI-PG
cd NohaPI-PG && docker compose up -d

はい、当社も料金をいただきます。

当社の料金は、各段階での取り分ではなく、支払う前に示される一つの定額です。People Pitchers Proは一席あたり月額₹2,499（GST別）、Kosmikのパスは₹51で7日間、₹101で30日間で、自動更新はされません。求職者はPeople Pitchersを無料で使え、クレジットが必要になる前に一日5回までAI機能を無料で使えます。Kosmikのゲストは一日3問まで無料で質問でき、Noha Payは誰でも当社に支払うことなく自分で動かせます。

よくある質問

よくある質問

どのように収益を上げるのですか？

定額で、支払う前に示します。People Pitchersの席、Kosmikのパスとレポートパック、ストアの開始後はストアの注文です。のちに、他の販売者向けのホスト版Noha Payを定額の月額で提供します。現在お金をいただくのは、Kosmikのパスとレポートだけです。

焦点が定まっていないのでは？

重点は、アプリの下にある共通の層です。サインイン、決済、ウォレット、WhatsAppメッセージ、AIのキャッシュは一度だけつくられているので、新しいアプリは最初からそのすべてを使えます。私たちの尺度は、新しいアイデアが有料ユーザーに届くまでの速さと、運用にかかる費用の小ささです。存在意義を示せないアプリは、延命せずに終了します。

リスクは何ですか？

大規模に支払ってもらえることは、まだ示せていません。これまでの入金は₹102です。ストアは規制対象のアーユルヴェーダ医薬品を処方箋に基づいてのみ販売するため、法務の承認後にしか開きません。WhatsAppのコードは現在、自社の中継を通しており、規模を広げる前に公式のWhatsApp Business APIへ移すべきです。また、本業のある三人にとって複数のアプリは多いため、できるだけ多くを共有しています。

連絡した後はどうなりますか？

認証コードでWhatsApp番号を確認していただきます。これで、メッセージが確かにご本人からのものだとわかります。メッセージはすぐに私たちに届き、創業者の一人からご返信します。
